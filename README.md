# Dalpex App — descargas

Instaladores oficiales de **Dalpex App**, el launcher de HaxBall de Dalpex:
estadios reales, hinchada con sonido, pelotas diferentes, avatar diferentes, modo Streamer, marcadores de TV, cámara de gol,
festejos y repeticiones de tus goles.

La app se compra y se administra desde **Dalpex Hub**. Este repositorio existe
solo para alojar los instaladores: el código es privado.

## Descargar

Última versión: **[Releases](../../releases/latest)**

| Versión | Instalador |
|---------|-----------|
| 1.1.0 | [Dalpex App Setup 1.1.0.exe](../../releases/download/v1.1.0/Dalpex.App.Setup.1.1.0.exe) |

Windows 10/11 de 64 bits. El instalador es de un solo click: instala y abre la
app.

## Soporte

Discord de Dalpex. Si Windows te avisa que el editor es desconocido, es porque
el instalador todavía no está firmado digitalmente — dale "Más información" →
"Ejecutar de todas formas".
